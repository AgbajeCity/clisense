# Data

The dataset is **disclosed synthetic** data for the Osun River corridor (Osogbo,
Osun State), generated by `app/model_core.py:generate_dataset()` to reflect the
corridor's published hydrology and climatology. Live CHIRPS, MODIS, NIHSA and
CliNode feeds were not accessible in the development environment.

Regenerate the CSV export with:

```bash
python -m data.generate_osun_dataset
```

This writes `osun_corridor_2016_2024.csv` (~3,282 daily records, 2016-2024).
Every value is generated, not measured.

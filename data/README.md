# data/

This directory contains the climate dataset used to train the Clisense ML pipeline.

## Contents

- `nigeria_climate_2015_2024.csv` — a real, committed 1,500-row sample of the
  Clisense synthetic climate dataset (not a placeholder). Columns: state, month,
  season, zone, rainfall_mm, temp_c, humidity_pct, wind_speed_kmh, rain_7d,
  rain_30d, rain_anomaly, dry_spell_days, temp_anomaly, threat_label.
- `generate_nigeria_climate_data.py` — the exact script (a thin CLI wrapper
  around `app/model_core.generate_synthetic_dataset`) used to regenerate the
  full dataset. Running it reproduces the full 18,530-row dataset the deployed
  model is actually trained on, with the same random seed.

## Regenerating the full dataset

```bash
python data/generate_nigeria_climate_data.py --n 18530 --seed 42
```

This writes `data/nigeria_climate_2015_2024.csv` with all 18,530 rows. The
1,500-row sample committed here is a reproducible subset (seed 7) kept in the
repo for quick inspection without needing to run the generator; the full
dataset is not committed as a separate large file. Both are generated by
the identical, single source-of-truth function in `app/model_core.py`, so
there is no drift between what you see here and what the live Streamlit app
and FastAPI backend train on.

## Honesty disclosure

This dataset is generated from climatological normals (seasonal rainfall,
temperature, and humidity baselines per state) rather than pulled live from a
sensor or satellite feed such as NASA POWER or CHIRPS. It faithfully reproduces
seasonal patterns (dry-season near-zero rainfall in the Sudan Savanna, wet-season
flood-level rainfall in the Southern Guinea Savanna) but does not capture
inter-annual variability the way real historical data would. See the main
README's "Limitations" and "Recommendations" sections for the plan to replace
this with live data.
